# Прошивка YK99

Рабочий файл проекта — [cart.bin](bin/cart.bin). Вариант VARIANT_CART управляет двумя моторами синусоидально. Команда меняется плавно, прошивка снимает тягу при отпускании кнопки. Совместимость зависит от конкретной силовой платы, а калибровка напряжения привязана к испытанному экземпляру.

| Файл | Назначение |
|---|---|
| cart.bin | Основная прошивка для проверенного направления обоих моторов |
| cart-diag.bin | Стендовая диагностика фаз, датчиков и пульта на вывешенных колёсах |
| cart-bench.bin | Ограниченный стендовый режим |
| cart-inv-l.bin, cart-inv-r.bin, cart-inv-lr.bin | Изменено направление левого, правого или обоих колёс |
| cart-test30.bin | Специальный тест вращения на вывешенных колёсах. Запускается отладчиком |

Проверка скачанных образов с macOS или Linux:

```sh
cd firmware/bin
shasum -a 256 -c SHA256SUMS.txt
```

## Из чего собрать ту же версию

Основа — [EFeru/hoverboard-firmware-hack-FOC, версия 4f141cbc](https://github.com/EFeru/hoverboard-firmware-hack-FOC/tree/4f141cbc97b297e194fd58e56444bd0322f902ac). Все изменения для этой сборки находятся в [патче тележки](patch/0001-VARIANT_CART.patch). В сборочный скрипт зафиксированы версия основы и PlatformIO 6.2.0. Скрипт загружает основу, накладывает изменения и собирает семь образов. Нужны git, Bash, Python 3 с venv, компилятор C для тестов и доступ в интернет при первой сборке.

Из корня репозитория:

```sh
./firmware/build.sh
./firmware/test/run.sh
```
