# Электротележка для доставки заказов

Четырёхколёсная тележка HAITEC HT-GW350 с двумя ведущими задними колёсами от 10-дюймового гироскутера. Курьер идёт впереди, поворачивает ручкой и удерживает кнопку тяги. После отпускания тележка катится по инерции. Аккумулятор предусмотрен съёмным для зарядки в помещении.

**Стадия проекта, ноябрь 2026 г.** Оба мотор-колеса вращались на стенде. Кожух платы примерен на раме. Цели для маршрута — груз 20–60 кг и 3–4 км в день. В опубликованных материалах нет испытания с таким грузом на маршруте.

Смета предусматривает 29 196 ₽ на привод и 12 694 ₽ на базовую тележку. Вместе 41 890 ₽. Варианты аккумулятора и запасные детали перечислены в смете. Это плановая стоимость комплекта.
